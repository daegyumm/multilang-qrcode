QR은 언어 중립 주소를 사용합니다. `npm run qr -- <확정된 HTTPS 기본 주소>`로 생성합니다.
네 면의 여백을 잘라내지 마세요. QR 아래에 안내 제목과 짧은 주소를 함께 표기하세요.

## 배포 전 현장 점검

- 한국어 원문과 네 언어 번역을 운영자가 검수
- iPhone Safari / Android Chrome 실제 기기 스캔
- 입구/시음 QR 목적지, 첫 언어 선택, 언어 변경, 새로고침 확인
- 현장 Wi-Fi와 이동통신 각각에서 첫 로딩 확인
- 실제 출력 크기·조명·거리에서 스캔 확인
- 안내 문구 수정 후 기존 QR로 새 내용이 표시되는지 확인

자동화는 Chromium 모바일 에뮬레이션을 사용합니다. 실제 기기·인쇄물·현장망 검증을 대체하지 않습니다.
첫 접속에는 인터넷이 필요합니다. 영상·음성·오프라인 캐시는 제공하지 않습니다.
